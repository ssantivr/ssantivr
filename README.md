## 03 — Proyecto destacado

### AgroSmirt

Sistema inteligente para el **monitoreo y automatización del riego de cultivos**.

AgroSmirt integra sensores conectados a **Arduino** para obtener información sobre la humedad del suelo y las condiciones ambientales.

Los datos son procesados mediante **Java** y almacenados en **MySQL**, permitiendo automatizar el control del sistema de riego.

**Características principales**

* Monitoreo de humedad del suelo.
* Análisis de condiciones ambientales.
* Automatización del riego.
* Control de motores y bombas.
* Generación de alertas.
* Registro y análisis de información.
* Optimización del consumo de agua.

**Stack**

`Java` `MySQL` `Arduino`
